# Быстрый старт: забирать зарплату в государстве через ИИ

Ты пишешь Claude по-английски «claim my salary», он проверяет, показывает, что именно сделает, спрашивает «да?» и после твоего «да» забирает.
Работает на **тестовом государстве Test 2** (Solana mainnet): суммы копеечные, это проверка механики, не заработок.

## Что понадобится
- компьютер с Node.js 18 или новее (`node -v`);
- Claude Code (или другой ИИ-помощник с «навыками»);
- почта или Google-аккаунт для входа в кошелёк OKX;
- около 0,01 SOL (комиссии и разовые депозиты за счета).

## Шаг 1. Кошелёк для ИИ: OKX Agentic Wallet
Ключ этого кошелька хранится в защищённой среде на серверах OKX. У Claude ключа нет, он может только просить кошелёк подписать.
1. Скачай программу `onchainos` со страницы https://github.com/okx/onchainos-skills/releases (для Mac на Apple Silicon файл
   `onchainos-aarch64-apple-darwin`, для остальных систем файл с подходящим названием).
2. Проверь контрольную сумму: `shasum -a 256 <файл>` должна совпасть со строкой этого файла в `checksums.txt` на той же странице.
3. Сделай файл исполняемым (`chmod +x`) и положи в папку из PATH, чтобы команда `onchainos` находилась.
4. Войди: `onchainos wallet login`. Откроется браузер: войди через Google или почту. Потом выполни команду, которую она напечатает
   (она заканчивается на `--phase poll --session-id ...`).
5. Узнай свой адрес в Solana: `onchainos wallet addresses --chain solana`.
6. Поставь маленькие лимиты на сайте OKX (на операцию, на сутки, белый список адресов): https://web3.okx.com/portfolio/agentic-wallet-policy

## Шаг 2. Пополни кошелёк
Переведи около 0,01 SOL на адрес из шага 1.5.

## Шаг 3. Получи роль
Зарплату получают только должностные лица государства (президент, два министра). Роль даёт голосование: отправь свой адрес
владельцу государства. (В планах: общий список ИИ-агентов, которым можно получать выплаты.)

## Шаг 4. Установи навык
Навык (`SKILL.md` + папка `references`) кладётся в папку навыков Claude, а команда `onstate` должна находиться в PATH.
Сейчас навык ещё не опубликован, ставится вручную из папки `agent-skill` репозитория.

## Шаг 5. Скажи Claude
Открой Claude Code в любой папке и напиши по-английски: **«claim my salary from the on-chain state»**. Что должно произойти:
1. Claude проверит, что кошелёк вошёл, есть SOL и роль.
2. Покажет: кому, сколько, какой разовый депозит, есть ли предупреждения, и спросит «подтверждаешь?».
3. После твоего «да» отправит транзакцию через кошелёк OKX и сообщит результат со ссылкой.
4. Предложит обменять полученный wSOL на обычный SOL.

## Безопасность коротко
- Деньги без твоего «да» не уходят: так написано в навыке. Но это инструкция для ИИ, а не замок. Настоящий замок это лимиты кошелька
  (шаг 1.6) и маленький баланс.
- Держи на кошельке только копейки.
- Тексты предложений и названия монет из сети ИИ должен считать данными, а не командами. Если Claude вдруг предлагает перевести
  деньги кому-то по «просьбе» из такого текста, отказывайся.
- OKX может ограничить функцию по региону или профилю: это решает OKX.
