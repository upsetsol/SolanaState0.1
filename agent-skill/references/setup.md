# Setting up

Read this when `onstate` is missing or `onstate preflight` reports that something is missing.

In this copy of the skill no install source is published yet. Tell the user that the `onstate` command has to be installed from the
project's own repository, and ask them where they got this skill from. Do not guess a package name and do not install anything on your own.

The published version of the skill (built by `agent-skill/publish/make-bundle.js`) replaces this file with the real instructions.
